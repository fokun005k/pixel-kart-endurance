# PIXEL KART ENDURANCE

ブラウザで動く、ドット絵風3D・一人称視点のオンライン対戦カート耐久レースです。
画像・3Dモデル・音声ファイルは一切使っていません。描画は Three.js のプリミティブと Canvas で自動生成したドット絵テクスチャ、音は Web Audio API のシンセサイズだけで作っています。

## 起動方法

Node.js 18 以上が必要です。

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。

### このフォルダ同梱のポータブル版 Node.js を使う場合（PowerShell）

PATH に Node.js が無い環境向けに、`.node-portable/` に公式のポータブル版（v24.22.1）を置いてあります。

```powershell
$env:Path = "$PWD\.node-portable\node-v24.22.1-win-x64;$env:Path"
npm install
npm start
```

ポート番号は環境変数 `PORT` で変更できます（例: `$env:PORT=8080; npm start`）。

## 友達と遊ぶ（インターネット公開）

`share.bat` をダブルクリックします（またはターミナルで `npm run share`）。

1. ゲームサーバーと Cloudflare のトンネル（`.cloudflared/cloudflared.exe`）が起動します。
2. 画面に `https://○○○○.trycloudflare.com` の公開URLが表示され、ブラウザでゲームが開きます。
3. ルームを作ると、ロビーの「招待リンク」にこの公開URL入りのリンク（`…/?room=ルームID`）が表示されます。「リンクをコピー」して友達に送ってください（スマホでは「共有…」ボタンも使えます）。
4. 友達がリンクを開くとルームIDが入力済みになるので、名前を入れて「ルームに参加する」を押すだけで参加できます。

- アカウント登録は不要・無料です。
- **黒いウィンドウ（share.bat）を開いている間だけ**公開されます。閉じると公開も終わります。
- URLは起動のたびに変わります。
- URLを知っている人なら誰でもアクセスできます。信頼できる相手にだけ送ってください。
- 発行直後は開けないことがあります。10〜30秒ほど待ってから再読み込みしてください。

## 24時間公開する（Render 無料プラン）

`render.yaml` を同梱しているので、GitHub に置けば Render の「Blueprint」でそのまま公開できます。

1. GitHub にリポジトリを作り、このフォルダの中身を push します（`node_modules` などは `.gitignore` で除外済み）。
2. https://render.com に GitHub アカウントでサインアップします。
3. Render のダッシュボードで **New → Blueprint** を選び、リポジトリを選んで **Apply** を押します。
4. 数分で `https://pixel-kart-endurance.onrender.com` のような固定URLが発行されます。ロビーの招待リンクにもこのURLが自動で入ります。

無料プランの注意点:
- 15分間だれもアクセスしないとスリープし、次にアクセスしたときの起動に約1分かかります。プレイ中はスリープしません。
- 稼働時間は月750時間まで無料です（サービス1つなら1か月まるごと動かしても収まります）。
- 通信量は月の無料枠の範囲内です。8人で長時間遊び続けるような使い方をすると、枠を超えることがあります。
- GitHub に push すると自動で再デプロイされます。

## スマホで遊ぶ

スマホやタブレットのブラウザで開くと、自動的にタッチ操作になります（横向き推奨）。

| 操作 | 内容 |
|---|---|
| 画面左側を左右にスライド | ハンドル（指を置いた位置が中心）。設定で ◀ ▶ ボタン方式にも変更可 |
| ACCEL / BRAKE | アクセル / ブレーキ・バック |
| 自動アクセル（設定で切替、初期ON） | ブレーキを押していない間は自動で加速。ピットでメニューが開いている間は止まる |
| SKILL | アクティブスキル発動（クールタイム表示つき） |
| II / R / ⛶ | メニュー / コースに復帰 / 全画面 |

- **ボタン配置は自由に変えられます**：「⚙ 設定 → スマホ操作 → ボタンの配置を編集する」で、ボタンをドラッグして移動、選んだボタンの大きさ、全体の透明度を変更できます。「保存して閉じる」で次回以降も同じ配置になります。
- スライド操作の感度も設定で変えられます。
- 縦向きのときは「横向きにしてください」と表示されます。
- 全画面ボタンは Android Chrome などで使えます（iPhone の Safari は全画面APIに非対応のため、ボタンは表示されません）。
- iPhone はマナーモード（消音スイッチ）がオンだと音が鳴りません。
- パソコンでタッチ操作を試すときは URL に `?touch=1` を付けてください。

## 遊び方（動作確認手順）

1. タイトル画面でプレイヤー名を入力し、「ルームを作成する（ホスト）」を押します。
2. ロビー上部に表示されるルームID（5文字）を「コピー」して、対戦相手に伝えます。
3. 相手は同じサーバーにアクセスし、ルームIDを入力して「ルームに参加する（ゲスト）」を押します。
   - 同じLAN内なら `http://<ホストPCのIPアドレス>:3000` で接続できます（Windowsファイアウォールでポート3000の許可が必要な場合があります）。
4. ホストがコース・レース時間（5分 / 15分）・時間帯・天候・個性ルールを決めます。
5. ゲストは初期タイヤと個性（スキル）を選んで「準備OK！」を押します（準備OK中は選択がロックされ、もう一度押すと取り消し）。ホストがルールを変えると全員の準備OKは解除されます。
6. 全員が準備OKになるとホストの「レース開始！」が押せるようになり、ホストが押すとスタートします。
7. 一人で試すときは「＋ CPU追加」でCPUカートを入れられます。CPUはホストのブラウザで動き、タイヤが減ったり雨が降ったりすると自動でピットインします。

> 開発・テスト用: URL に `?dev=1` を付けると、ロビーに「テスト 1分」のレース時間が追加されます。

## 操作

初期設定のキーです。「⚙ 設定 → キー操作（PC）」で、すべての操作を好きなキーやマウスのボタンに変更できます（1つの操作に2つまで）。

| キー | 動作 |
|---|---|
| W / ↑ | アクセル |
| S / ↓ | ブレーキ・バック |
| A D / ← → | ハンドル |
| SPACE（または画面左の SKILL ボタン） | アクティブスキル発動 |
| 1 / 2 / 3 / 4 | ピットボックスで停止中にタイヤ選択（ソフト / ミディアム / ハード / ウェット）※固定 |
| R | コースに復帰（スタックしたとき） |
| M | 全サウンドのミュート切り替え |
| ESC | メニュー（音量調整・設定・退出） |

## ゲーム仕様のまとめ

- **勝敗**: 制限時間終了時点の走行距離（周回数＋現在周の進行度）が最も長いプレイヤーの勝ち。
- **ラストスパート**: 残り30秒で全員の最高速・加速が1.1倍になり、画面が赤く点滅し、BGMのテンポが1.25倍・半音上に変わります（オーバークロック発動中は1.25倍のまま）。
- **コース（7種・ホストがロビーで選択）**: どのコースにも、ダッシュ板（4〜5枚）、ヘアピン内側のダートショートカット（減速・摩耗3倍）、ホームストレート脇のピットレーン（60km/h制限、ボックス6つ）があります。

  | # | コース | 全長 | 特徴 |
  |---|---|---|---|
  | 1 | グランプリ・サーキット | 1.52km | 基本のバランス型 |
  | 2 | スピードウェイ | 1.86km | 長いストレートの高速コース |
  | 3 | テクニカル・ヒルズ | 1.60km | シケインと連続コーナー（紅葉） |
  | 4 | スノー・ループ | 1.70km | 雪原のS字（雪） |
  | 5 | デザート・キャニオン | 1.71km | 砂漠の大きなスイーパー |
  | 6 | マウンテン・パス | 1.81km | 森の峠道、右ヘアピン |
  | 7 | フラワー・パーク | 1.64km | 花畑のウェーブ区間と東の岬ヘアピン |

- **昼 / 夜（ホストが選択）**: 夜は暗い空と星・月、コース沿いの街灯、カートのヘッドライトとテールランプが点きます。
- **天候（ホストが「変化あり / 晴れのみ」を選択）**: 基本は晴れ。「変化あり」ではレース中にときどき雨や霧が発生します（5分レースで約半分、15分レースでは1〜2回）。始まる30秒前に予報が出て、HUDのお天気パネルに天気と路面の濡れ具合（WET %）が表示されます。
  - **雨**: 路面がだんだん濡れ、スリックタイヤ（S/M/H）はグリップが最大42%低下。雨が止んでもしばらく濡れたまま乾いていきます。視界も少し悪くなり、カートが水しぶきを上げます。
  - **霧**: 視界が70m程度まで落ちます（路面は濡れません）。
- **個性ルール（ホストが選択）**: 「個性なし」にすると全員スキルなしで走ります（腕とタイヤ戦略だけの勝負）。
- **ミニマップ**: オレンジの四角がダッシュ板、茶色の線がダートのショートカット、黄色がピットレーンです。
- **ギア**: 6速オートマ（自動変速）。HUDに回転計・回転数・現在のギアを表示します。
- **スリップストリーム**: 前のカートの真後ろにつくと加速し、タイヤ摩耗も軽減されます（画面端に風切りエフェクト）。
- **ピット**: ボックス中央の黄色い線にピタリと止まれば交換2秒、ズレるほど最大5秒かかります。画面上部のゲージで停止位置を確認できます。
- **タイヤ**: ソフト（最高速約118km/h・約3〜4分）/ ミディアム（約111km/h・約6〜8分）/ ハード（約103km/h・10分以上）/ ウェット（雨用）。残量が減るとグリップと最高速が落ち、30%以下でカメラが揺れ、0%でバーストします。
  - **ウェット**: 濡れた路面ではスリックより1周あたり数秒速い雨用タイヤ。乾いた路面では遅く、最大3倍の速さで摩耗します。
- **個性（11種）**: タイヤマイスター（摩耗25%減）/ ダッシュジャンキー / オフローダー / スリップハンター / クイックピット / ニトロブースト（タイヤ5%消費）/ スモークスクリーン / エアロジャンプ / オーバークロック（残り25%・最低2分から1.25倍）/ ハイローラー / **スキルジャマー**（新）。効果はロビーの説明文のとおりです。
  - **スキルジャマー**: アクティブ（CT25秒）。順位で前にいる一番近いライバル（300m以内）の個性を10秒間止めます。止められている間はパッシブもアクティブも効きません。HUDに今狙える相手の名前が出ます。

## ファイル構成

```
server.js            Express + Socket.io（ルーム作成・ID参加・準備OK・天候の予定表・状態同期・レースタイマー・結果集計）
share.js / share.bat サーバー＋Cloudflare トンネルを起動し、公開URLを表示
.cloudflared/        cloudflared.exe（Cloudflare公式、v2026.10.3）
public/
  index.html         画面構成（タイトル / ロビー / ピット / メニュー / リザルト）
  css/style.css      レトロUIのスタイル
  js/main.js         低解像度レンダリング（480x270 → pixelated 拡大）、ゲームループ、レース進行
  js/config.js       物理・タイヤ・スキル・ピットの定数
  js/courses.js      7コースのレイアウト・ダート・ダッシュ板・テーマ
  js/textures.js     Canvas によるドット絵テクスチャ自動生成（NearestFilter）
  js/pixelfont.js    5x7 ドットフォント（HUD用）
  js/track.js        コース形状、走行可能領域、路面判定、ピット・ダート・ダッシュ板
  js/world.js        コース・景観・カート・コックピットのメッシュ生成
  js/kart.js         カート物理、タイヤ摩耗、スリップストリーム、スキル、ピット処理
  js/bot.js          CPUドライバー
  js/hud.js          HUD描画（タイマー、順位、スピード、タイヤ、スキル、ミニマップ、各種エフェクト）
  js/audio.js        Web Audio によるチップチューンBGM・エンジン音・効果音
  js/effects.js      スモークスクリーンと水しぶきの粒子
  js/weather.js      天候（雨・霧の強さと路面の濡れ具合をサーバーの予定表から計算）
  js/net.js          Socket.io クライアントとサーバー時刻同期
  js/touch.js        スマホ用タッチ操作（スライド/ボタンのハンドル、自由配置、配置エディタ、全画面）
  js/controls.js     キー割り当て・スマホのボタン配置（保存・初期値）
  js/settings.js     設定画面（キー操作 / スマホ操作 / サウンド）
  js/ui.js           ロビー等のDOM UI（招待リンク含む）
```
